ตอนนี้ (V3 ปัจจุบัน)

ธีมมืด ใช้สี accent 5 สี (ชมพู/ม่วง/ฟ้า/ส้ม/เขียว) + กราเดียนต์ + glow + glassmorphism + อนิเมชัน GSAP หนาแน่น — ดูจัดเต็มแต่สายตาไม่มีจุดพัก

เป้าหมาย (Pixel Minimal)

วิเคราะห์จากโค้ดจริงใน repo — สิ่งที่ต้องแก้เหมือนกันทุกแบบ

1 · Design tokens (จุดคานงัดหลัก)

สี ฟอนต์ และ effect ทั้งหมดรวมอยู่ใน app/globals.css (~420 บรรทัด) — เปลี่ยนพาเลต 5 accent เหลือ 1–2 สี, ลบคลาส gradient/glow/glass ราว 15 คลาส, เพิ่มคลาสพิกเซล (border หนา, offset shadow, stepped corner, dither)

2 · Components ที่ต้องรื้อ presentation (9 ไฟล์ ~3,800 บรรทัด)

  • HeroSection (445) · AboutSection (453) · SkillsSection (489) · ExperienceSection (668) · ProjectSection (725) · ProjectCard (400)
  • Navbar (330) · Footer (236) · GridBackground (68) — โครง section และ data ไฟล์ (data/*.ts) ใช้ต่อได้ทั้งหมด แก้เฉพาะหน้าตา
  • มีสี hard-code ในโค้ดเยอะ เช่น text-[#a1a1aa], border-[#262626] — ต้อง sweep เปลี่ยนเป็น token กลางไปพร้อมกัน

3 · Typography

เพิ่มฟอนต์พิกเซลผ่าน next/font/google (มากับ Next.js ไม่ต้องลงเพิ่ม): Press Start 2P (พิกเซลจัดเต็ม) หรือ Silkscreen (พิกเซลอ่านง่ายกว่า) สำหรับหัวข้อ — เนื้อความยังใช้ Geist/mono เดิม ส่วนภาษาไทยแนะนำเพิ่ม IBM Plex Sans Thai ถ้ามีเนื้อหาไทย

4 · Animation

ลด GSAP timeline ยาว ๆ (เช่น grid-line loop 24 เส้นใน Hero) เหลืออนิเมชันจังหวะพิกเซล: ease: "steps(n)", typewriter, cursor blink — ใช้ gsap ตัวเดิมได้ และแนะนำถอด motion ออกเพราะซ้ำหน้าที่กับ gsap (ลด bundle)

5 · รูปภาพ

รูปโปรไฟล์/สกรีนช็อตเดิมใช้ต่อได้ — ใส่กรอบพิกเซล + image-rendering: pixelated เฉพาะ element ตกแต่ง (ไม่ใส่กับรูปถ่ายจริง) แบบ E ใช้ filter: grayscale(1) แล้วคืนสีตอน hover

ข่าวดี: ทางหลักไม่ต้องลงไลบรารีเพิ่มเลย

ไม่ต้องลงเพิ่ม (ใช้ของที่มี)

  • Tailwind CSS 4 — ทำ border/shadow/dither ทั้งหมดได้ด้วย utility + token ใน globals.css
  • next/font — โหลดฟอนต์พิกเซล (Press Start 2P / Silkscreen / VT323) ได้ในตัว
  • gsap — พออนิเมชันแบบ steps()/typewriter แล้ว

แนะนำให้ลงเพิ่ม (ตัวเดียว, เบา)

  • npm i pixelarticons — ไอคอนพิกเซล 480+ ตัว (MIT, SVG) ใช้แทน lucide-react ให้ไอคอนเข้าธีม ทุกแบบ A–E ได้ประโยชน์

ทางเลือก (เฉพาะบางแบบ / ไม่บังคับ)

  • nes.css — ชุด UI พิกเซลสำเร็จรูป เข้ากับแบบ C แต่ไม่แนะนำ: ชนกับ Tailwind และทำให้ไม่มินิมอล ทำเองคุมได้มากกว่า
  • ถอด motion ออกจาก package.json — ไม่ใช่การลงเพิ่มแต่ช่วยลดขนาด เพราะซ้ำกับ gsap
ขั้นถัดไป: เลือกแบบที่ชอบ (A–E) หรือจะผสมก็ได้ เช่น "โครงแบบ A แต่ใช้สีแบบ B" — เลือกแล้วผมจะรื้อ token ใน globals.css ก่อน แล้วไล่แก้ทีละ section: Navbar → Hero → About → Skills → Experience → Projects → Footer
